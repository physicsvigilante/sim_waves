## Closing lines
1. Most steps were one-line edits and the engine's numbers were sensible, so a teacher could vary a scene quickly in a real class.
2. It would not yet be smooth: getting a number at a given point needs an `illustrate` trick, an empty `minima` list aborts a run, and a list-valued observe crashes the viewer.
3. The page views are plain plots with no explanation or labels for students, so a class would still need the teacher to narrate them.
